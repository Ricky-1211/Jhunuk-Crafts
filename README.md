# Jhunuk Crafts

A frontend-only handmade crafts website built with **Next.js 14, React, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons**.

## About the Project

Jhunuk Crafts is a creative e-commerce-style frontend prototype showcasing handmade products, artistic decorations, jewellery, accessories, and unique craft items.

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
```

## Project Features

- Handmade product showcase
- Product categories
- About Us page
- FAQ page
- Contact page
- Privacy Policy page
- Responsive website layout

## Project Structure

- `app/` – Website pages and routes
- `components/` – Reusable UI components
- `lib/data.ts` – Product and website sample data
- `public/` – Static assets

## Note

This is currently a frontend demonstration project. It does not include a backend, database, authentication, online ordering, or payment integration.
